# Exact package versions the project was developed with (Python 3.11, Windows), frozen on 2026-10-12.
#
# The simplest way to use this file is setup.bat, which creates .venv, installs these
# packages and then downloads the model weights. By hand:
#
#   with uv:   uv venv .venv --python 3.11
#              uv pip install --python .venv\Scripts\python.exe --no-deps --index-strategy unsafe-best-match -r requirements.txt
#   with pip:  py -3.11 -m venv .venv
#              .venv\Scripts\python.exe -m pip install --no-deps -r requirements.txt
#
# A requirements file can only install Python packages. The model weights are files, not
# packages: scripts/download_models.py fetches them, and the demo fetches any that are
# still missing the first time it runs.
#
# --no-deps matters: ultralytics and rtmlib both ask for "opencv-python" (and rtmlib for
# the CPU build of ONNX Runtime), which would be installed on top of opencv-contrib-python
# and onnxruntime-gpu and overwrite parts of them. Every package they really need is
# already listed here.
# torch and torchvision are the CUDA 13.0 builds from the PyTorch index named below (they
# carry the GPU libraries that ONNX Runtime also uses). An NVIDIA graphics card with a
# recent driver is needed for the GPU models; MediaPipe runs on the CPU.
